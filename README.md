# Incredulous AI

AI-powered fact generator delivering daily astonishment.

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

```bash
git clone git@github.com:Monte9/incredulous-ai.git
cd incredulous-ai && yarn

yarn dev
```

Navigate to [http://localhost:3000](http://localhost:3000) to start developing.

### Tools

- Tracking signups on Airtable
- Analytics on Mixpanel
- Deployed on Vercel
